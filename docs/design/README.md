# Web 管理后台设计原型

tether-hub 网页的 5 套重新设计。每个文件自包含（内联 CSS/JS 与假数据），直接用浏览器打开即可；右下角的小页签用于在「登录 / 主界面 / 接管终端 / 审计」之间切换，接管终端视图里还可以切换 5 种接管状态。也可以用地址锚点直达，例如 `03-cyanotype.html#term:reclaimed`。

| 文件 | 名称 | 风格要点 | 适合的场景 |
|------|------|----------|------------|
| [01-cream.html](01-cream.html) | 奶油 | 沿用 Tether 客户端「奶油」主题：燕麦底、奶白软垫卡片、焦糖主色、Nunito 圆体；顶部蜂蜜色横幅集中列出等待确认的会话，左侧机器栏 + 右侧按机器分组的会话列表 | 希望 hub 与客户端观感一致、日常长期挂着看 |
| [02-switchboard.html](02-switchboard.html) | 交换台 | 电话交换台隐喻：钢灰面板、标签机色带写机器名、黄铜按键；顶部「信号灯牌」每个会话一盏灯，等待确认的灯琥珀色闪烁；机器是竖排接线板，接管视图里状态是一排指示灯 | 机器、会话较多，想一眼扫完全局状态 |
| [03-cyanotype.html](03-cyanotype.html) | 蓝图 | 晒图纸底与网格线、Saira 窄体；首屏是 hub 到各机器的连接拓扑，会话以「明细表」列出，等待确认的行用工程图「修订云线」（橙色虚线框 + 三角修订号）圈出；终端视图底部是图纸标题栏 | 偏技术、喜欢把连接关系画出来 |
| [04-swiss.html](04-swiss.html) | 瑞士 | 国际主义排版：纯白纯黑、12 栏网格、Archivo 窄体粗黑大字与粗规线；等待确认时整条红色海报区占据首屏，其余地方只有黑白 | 只关心「现在有没有要我处理的」，信息密度高、对比强 |
| [05-riso.html](05-riso.html) | 孔版 | 双色孔版印刷小册子：蓝色油墨、荧光粉套色错位标题、实心错位投影、网点底纹；黄色只当荧光笔划出等待确认的行；审计按天排成时间线 | 个人自用、想要轻松一点的气质，手机上查看也舒服 |

共同约定：

- 「Claude 等待确认」在每套里都是全页最醒目的元素，且只有它使用该套的强调色。
- 每个未退出的会话都有「接管」按钮；已退出的会话淡化且不可接管。
- 终端区域用 flex + `min-height: 0` + 内部滚动，内边距放在滚动容器外（或容器内的块级内边距），保证最后一行不被裁切。
- 宽屏为主，640–900px 以下切为单栏；在 400px 宽度下自检过。
