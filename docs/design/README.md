# Web 管理后台设计原型

tether-hub 网页的 5 套设计原型，均为常规现代中后台风格（简约、圆角、少边框，主色 + 中性灰 + 一种警示色），并专门适配手机（390px）。每个文件自包含，浏览器直接打开；页面内的原型切换器可在「登录 / 主界面 / 接管终端 / 审计」间切换，也可用锚点直达（`#login` `#main` `#term` `#audit`）。多数支持 `?theme=light|dark` 强制主题，默认跟随系统。

**已选定：04 主从布局**，据此实现 `public/` 下的正式页面。

| 文件 | 布局 | 手机端 |
|------|------|--------|
| [01-antd.html](01-antd.html) | Ant Design Pro 经典：深色侧栏 + 顶栏 + 可展开会话子表的机器表格，Ant 蓝 | 底部导航（带角标），表格转卡片 |
| [02-element.html](02-element.html) | Element Plus：浅色侧栏 + 统计卡 + 每台机器一张会话表卡片，Element 蓝 | 抽屉 + 底部导航，会话卡片 |

| [05-compact-table.html](05-compact-table.html) | 紧凑表格：所有会话平铺一张大表 + 筛选栏 + 分段控件（会话 / 机器 / 审计），可展开行 | 3 行卡片 + 横向快捷筛选 + 底部筛选面板 |

共同约定：

- 「Claude 等待确认」是全页最醒目的元素（顶部提醒 + 行底色 + 标签），警示色只用于它和异常状态。
- 未退出的会话有「接管」按钮；离线机器或已退出会话不可接管。
- 接管终端在手机上全屏，高度跟随 `visualViewport`（软键盘弹出时贴底），底部按键条提供 Esc / Tab / Ctrl+C / 方向键；终端最后一行不得被裁切。
- 手机触控目标 ≥ 44px。
